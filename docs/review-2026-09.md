# YapWorld — project review & Dutch roadmap (September 2026)

*Full-project review plus the roadmap that was executed from it, with a focus
on the Dutch pack (`dutch-nl`). Status column reflects what shipped on the
`claude/dutch-app-review-roadmap-pngpib` branch.*

---

## 1. State of the project before this pass

- **Engine** (~1,300 lines of React): sound architecture (engine vs. pure-data
  packs, validator as the CI gate). Lint, build and validate all green.
- **Dutch pack**: 98 of 126 days authored (A1 → B1 core, B2 weeks 13–14).
  Content is strong; the validator caught schema errors, but nothing checked
  the *Dutch* itself. Weeks 15–18 (days 99–126) were outlined in
  `roadmap-dutch-nl.md` but not written.
- **No tests** of any kind; CI only ran the pack validator.

## 2. Flaws found

### Engine

| # | Flaw | Impact | Fix |
|---|------|--------|-----|
| E1 | App fetched **every lesson file** (126 requests, 28 of them 404s) when a language was chosen | Slow dashboard, noisy network, brittle on flaky hosting | Per-pack `index.json` (generated by `tools/build-index.js`); lessons load lazily on open; validator fails on a stale index |
| E2 | Streak used the **UTC** date | A learner in the Netherlands at 23:30 got tomorrow's date; streaks broke around midnight and DST | Local calendar date; streak shown only while alive |
| E3 | Grader rejected `’t is` (curly apostrophe), `ĳ` ligature, commas, quoted answers | Correct Dutch marked wrong | Normalisation for all of these; the `'` of `'t` is preserved |
| E4 | One-letter typos gave a flat "Not yet" | No feedback loop for near misses | Damerau edit distance; "Almost — one letter off" nudge (never counts as correct) |
| E5 | Voice picker fell back to **any** `nl` voice, so a Flemish `nl-BE` voice could narrate a "Not Flemish" course | Wrong accent model for the learner | Prefer exact locale; `manifest.audio.avoidLocales` / `preferredVoices` |
| E6 | Chips without `speak` were silent | Missed audio | Fall back to `nl` |
| E7 | Dialogue lines were clickable `div`s | Not keyboard reachable | Real buttons |
| E8 | No way to type é/ë/ï on many keyboards | Learners forced to rely on diacritic tolerance | Tap-to-insert accent keys (`manifest.specialChars`) |
| E9 | Lesson end only offered "back to dashboard"; dashboard always opened week 1 | Friction between days | "Next day" button; dashboard opens the learner's current week |
| E10 | `journal.minSentences` was in the schema but ignored | Season-2 journals had no nudge | Sentence counter against the target (never blocks) |
| E11 | Chrome strings hard-coded in English | Packs could not localise feedback | Every string goes through `ui()`; Dutch strings in the manifest |
| E12 | No tests, no lint/build in CI, two lint warnings | Regressions invisible | `node --test` suites for grading, progress, voice selection; `ci.yml` runs lint + test + build |
| E13 | Validator did not check `level`, `unit`, `durationMin`, empty/markdown answers, duplicate MCQ options | Schema drift possible | Added |
| E14 | No retention mechanism at all: words met on day 3 were never seen again | Weak learning loop | **Vocabulary review**: spaced flashcards over every chip from finished lessons |

### Dutch content (found by the QA passes)

Representative fixes (full list in the commit message of the QA commit):

- *Dit is mijn vriend* → *een vriend van mij* (reads as "my boyfriend").
- *Kunt u pinnen?* asked the shopkeeper whether *they* could pay by card → *Kan ik pinnen?*
- *het raam werd gebroken* not idiomatic; *de soep was al warm* was an adjective, not the state passive the block claimed to teach.
- MCQs with two defensible answers (e.g. *werd de tafel al gedekt*), a comprehension question the dialogue never answered, a `sample` that was not a regret form.
- Builders that could produce *een huis leuk*, *Ik denkt*, *want ik ziek ben*, *Kijk nou zitten*.
- Article errors: *de zout*, *De imperfectum*; *Sanne's* → *Sannes*; a Flemish-leaning `er` placement in journal starters.
- Continuity: an exchange implied Bram had left Rotterdam; *vorige maand* for a move seven days earlier; season-2 durations and capstone journal minimums aligned to the style guide.
- Typed/dictation answer lists: real variants added (both verb-cluster orders, *graag* phrasings, fronted subclauses, *mij/me × kunnen/willen* grids), dead case/punctuation duplicates removed.
- Season 2 (days 99–126, written in this pass and then independently edited): the one-year timeline enforced (*vorig jaar*, *anderhalf jaar*, never *twee jaar*), Emma's career step kept unresolved, a swapped *rode/groene volgorde* label, an ungrammatical builder cross-product, *een oplevering doen* → *er wordt opgeleverd*, the job interview reframed as a role-play so the learner is not suddenly an outside candidate at their own agency.

## 4. What is still open (recommended next)

1. **Human native-speaker read-through before public launch.** Every day has
   now had an authoring pass plus one independent editorial pass, and the pack
   validates strict-clean, but a human read of the dialogues (season 2 above
   all) is still the right release gate.
2. **Pre-generated audio.** Web Speech quality for `nl-NL` varies a lot by
   device (Android often has no Dutch voice at all). The `speak` field is
   already the contract; add `audioUrl` support in `audio.js` and a batch TTS
   step in `tools/`.
3. **Grammar-aware grading for builders.** Builders still complete on "one chip
   per slot"; a `correct` combination (or list) in the schema would let the
   engine grade them. Schema v2 item.
4. **Other packs.** German/Italian/Spanish are at 98/126 days and have not had
   the QA pass. The Dutch QA prompt transfers directly.
5. **Progress sync.** `auth.js` is backend-shaped; a real provider plus a
   progress sync layer is the obvious next product step.
